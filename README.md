# Aura Messenger

Готовый лендинг и веб-мессенджер Aura.

## Что внутри

- `/` — продуктовая страница Aura Messenger с официальными текстами, анимациями и интерактивным превью интерфейса.
- `/app.html` — сам мессенджер в браузере.
- Кнопка **Скачать приложение** определяет устройство и запускает PWA-установку или показывает инструкцию.
- Кнопка **Открыть в браузере** сразу ведёт в рабочую веб-версию.

## Запуск

```bash
npm install
npm start
```

После запуска:

```text
http://localhost:3000/          — лендинг Aura
http://localhost:3000/app.html  — мессенджер
```

## Примечание

PWA-установка полноценно работает на HTTPS-хостинге и на `localhost`.
